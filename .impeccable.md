# magerblog Design Context

## Design Context

### Users
Developer-adjacent readers, indie builders, and AI practitioners. Consuming on desktop mostly, occasionally mobile. Here to read technical takes, cooking experiments, and life notes from a builder in Chicago.

### Brand Personality
Terminal-meets-editorial. Three words: **Sharp. Alive. Opinionated.**
Voice is high signal, low noise — like a pull request with a strong commit message.

### Aesthetic Direction
Dark-first (GitHub terminal palette: #0D1117, #010409, #30363D). Neon accents: cyan (#79C0FF), purple (#A371F7), green (#3FB950). Cosmic homepage variant uses light warm paper (#f5f3f0 / #faf8f5).
Font system: Syne 800 for display wordmarks, JetBrains Mono for metadata/labels, Space Grotesk for UI/nav, Atkinson/Source Serif for body.
References: Craig Mod's newsletter, The Verge circa 2023 (editorial boldness), terminal tools like Warp.
Anti-references: generic SaaS landing pages, Bootstrap defaults, any footer that looks like it came from a template.

### Design Principles
1. **Typography carries the weight.** Let type do the design work before reaching for color.
2. **Monospace as texture.** JetBrains Mono for metadata creates tactile contrast against display fonts.
3. **Delight in the detail.** Small interactions (cursor blink, hover lift) earn trust without shouting.
4. **Dark is the canon.** Light mode is a visitor; dark terminal is home.
5. **Signal over decoration.** Every element must earn its space — no filler.
