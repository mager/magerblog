Quick update: the mager-bench dashboard now lives at its own domain, [bench.mager.co](https://bench.mager.co). Same data, same scoring — just a proper home instead of a Vercel preview URL, which makes it easier to check when a new model drops.

If you're wondering what mager-bench is, [the original post](/blog/2026-07-05-mager-bench/) covers the whole thing: five coding tasks I care about, run against any set of models, scored on correctness, documentation, and style.
