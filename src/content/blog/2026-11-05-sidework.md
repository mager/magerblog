Coding agents have changed what I can build for myself. I can build my own custom Salesforce clone in 10 minutes. I can build a social network for people who collect Japanese camera lenses. Once I have something working, I can keep working on it with an agent indefinitely, changing it as I use it.

Agents are also helping me finish side projects that might otherwise have stayed half-built. But then where does the finished thing go? I can be proud of a project, put its source on GitHub, post a link, and still leave it sitting there with no easy way for someone else to discover it.

GitHub and Hugging Face are not giving me the browsing experience I want for personal software. I want to see what people made, understand what it does, and try it. If someone built one useful little tool, I want to see what else they made.

That is what I want [Sidework](https://sidework-ten.vercel.app/mager/) to be: a shelf for your personal software, where you can put the projects you are proud of and share them with the world. Each project should explain what it does, who it helps, and how to use it. I want to build a social network around those projects and the people behind them.

This started because I wanted to contribute to four more open source projects within a week and keep track of that work. But I also wanted a place for my own software. Both tell you something about what I like to build.

## Projects and contributions

[Homeport is a project I built](/blog/2026-10-04-homeport/). My [pull request to Impeccable](https://github.com/pbakaus/impeccable/pull/1157) added a way to copy all findings from the browser extension popup. I want both on my profile, with enough context to understand the work and links to see it for yourself.

The project with the most stars is not always the one that is most useful to you. I want Sidework to help people find software they might never hear about otherwise, and follow the `@handles` of the people who make it.

## Setting up a profile through MCP

I also wanted an agent interface from the start. If I am already working with a coding agent, I should be able to ask it to help prepare my Sidework profile.

The prototype includes a Model Context Protocol (MCP) endpoint at `/api/mcp` and a Claude Code plugin. Tools such as `get_profile`, `list_github_repositories`, and `prepare_profile_draft` let an agent inspect the existing profile, find public repositories, and prepare a draft with up to six projects.

The intended request is simple: “Set up my Sidework profile from my public GitHub repositories.” The agent can gather facts and prepare descriptions, then return a review link. I inspect the result in the browser before saving it. The [agent setup guide](https://github.com/mager/sidework/blob/main/docs/agents.md) covers the connection and plugin installation.

**This is the very first version of Sidework, and my first post about it.** We are still building the onboarding flows, social interactions, user interface, and profile pages. I am sharing it now so people can try it while we build.
