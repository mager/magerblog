May was a sabbatical month. I was in Japan for three weeks, which gave me time to think, to watch things, and — somewhat inevitably — to rebuild my AI setup from the ground up.

## The Japan part

The sports were the highlight.

I'd been looking forward to [the sumo tournament in Tokyo](/blog/2026-05-11-grand-sumo-tokyo) since I saw it on the calendar. We almost missed it — I miscalculated the timezone when tickets went on sale and the straightforward option disappeared before I checked. We ended up going through Japan World Tours, which turned out to be the right call: a guide named Kaz gave us thirty minutes of context before we went in, and a guy named Nick who was planning to attend all fifteen days sat next to us and gave running commentary. By the end we were Enho fans. The Yokozuna was injured and didn't appear, but the bow twirling ceremony at the end was worth the admission on its own.

One detail I hadn't expected: the only meat sold there is chicken. No beef, no pork. Chickens stand on two feet like sumo wrestlers. Cows and pigs don't fit the symbolism. That kind of rule — applied all the way down to the concession menu — is the reason the whole thing feels dense with intention.

The [Hanshin Tigers game in Osaka](/blog/2026-05-20-hanshin-tigers-baseball) was the other one. We sat in the right-field cheering section at Koshien, which is either the only way to experience Japanese baseball or, at minimum, the correct starting point. Every batter has his own chant. Trumpets and drums run the whole section, directed by a drum major. The older couple behind us handed us a pole weiner and a packet of vinegared kelp as a kind of peace offering. We drank gin lemon sours and watched the Tigers fall behind 7-0, claw back to tie in the 8th, and win on a walk-off home run in the bottom of the 9th. I watched the video afterward to make sure it actually happened.

The name "Tigers" traces directly to the Detroit Tigers — the Hanshin founders named the team after them on purpose, to echo the heavy-industry connection. My wife grew up in Detroit, so she was already a fan.

## Blowing up the harness

I spent longer on the setup side than I intended, but most of it happened from hotel rooms, which is its own kind of satisfaction.

In early May, Anthropic shipped most of what I'd been building [OpenClaw](https://mager.co/blog/2026-02-22-openclaw-mac-mini-tailscale) to do — Managed Agents, Multi-agent Orchestration, Dreams, Routines, Remote Agents — all at once at Code w/ Claude. I also shipped a small harness called conseiller around the same time, testing their new advisor tool, which lets a fast executor model consult Opus mid-generation and pay Opus rates only for the planning calls. [That post](/blog/2026-05-08-advisor-strategy-principal-agent) maps every piece of the OpenClaw setup to its Anthropic-native equivalent.

From Tokyo, I [killed OpenClaw for real and replaced it with native Claude Code tooling](/blog/2026-05-13-killing-openclaw) — the Telegram channels plugin, a `CLAUDE.md` pulling in the brain files, and a Pro subscription instead of the API bill. The whole migration took about forty minutes, with Claude Code on my laptop driving the Mac mini in Chicago over SSH and tmux. `capture-pane` is the part of that story worth reading if you've never set up a remote agent session this way.

Then I came back and finished the job at the end of the month. [plexus](/blog/2026-05-30-build-your-own-ai-harness) is the harness I ended up with: roughly 250 lines of TypeScript, two-tier model routing (Sonnet by default, Opus for code and research via a Haiku classifier), Telegram and CLI channels, and the Agent SDK doing the actual inference. OpenClaw's gateway is off. plexus is running under `screen` on the mini, pointed at the same bot token.

## The brain

The flat-file brain worked until it didn't. Seven markdown files `@`-imported into `CLAUDE.md` at session start — all of them, every time, regardless of what the session was actually about. That's fine for thirty episodic entries. It doesn't scale.

I [migrated everything into gbrain](/blog/2026-05-20-gbrain-brain-migration), Garry Tan's open-source semantic memory system: embedded Postgres via WASM, hybrid vector + keyword search, wikilink graph built from document structure without any LLM calls at import time. The new `CLAUDE.md` lists page slugs instead of `@`-imports. Identity and soul load unconditionally because they're short and always relevant; everything else is fetched on demand. A session about CSS doesn't carry the full BeatBrain project history for no reason.

The one technical gotcha worth noting: `cat file.md | cd ~/Code/gbrain && bun run src/cli.ts put slug` does not work — the `cd` runs in a subshell and doesn't affect the subsequent command. `cd` first, then redirect stdin. I learned this slowly.

Karpathy posted his four rules for agentic coding around the same time, and Forrest Chang turned them into a [CLAUDE.md file](https://github.com/multica-ai/andrej-karpathy-skills/blob/main/CLAUDE.md) that's now at 220K combined GitHub stars. [My post on it](/blog/2026-05-22-karpathy-claude-md) is less about the rules themselves and more about what it means to have the person who diagnosed these failure modes — "models make wrong assumptions on your behalf and barrel ahead without checking" — now on the pre-training team at Anthropic. Prompt engineering patches the output. Pre-training changes the default.

## Ecosystem things I was reading

[SkillOpt](/blog/2026-05-26-skill-evals-skillopt) is a Microsoft Research paper that treats SKILL.md files as trainable parameters — propose bounded edits, evaluate on held-out examples, accept only on strict improvement. The constraint that the median final skill file was around 920 tokens is the useful takeaway: skills don't need to be long, they need to be high-signal. Most skill files I've seen are longer than they should be because length feels like effort.

[OpenHuman](/blog/2026-05-25-openhuman-explainer) crossed 27k stars. It's a desktop-first agent harness built in Rust/Tauri, with 118+ OAuth integrations and a compression layer that strips HTML down to Markdown before it hits the context window. Different category from what I'm building — they're optimizing for low-friction setup, I'm optimizing for ownership — but worth watching for the memory architecture.

Earlier in the month I built [llocal](/blog/2026-05-06-local-gemma-kotsu) — a Go Bubble Tea TUI for local model servers — mostly because I wanted something that would work on a plane. The useful thing was the HTTP boundary: the TUI sends chat messages to an OpenAI-style endpoint and doesn't care what's running behind it. Used Gemma 4 through llama.cpp to generate kanji mnemonic data for Kotsu, my Japanese learning app.

## Food

I came home from Japan and immediately made [wafu butter soy spaghetti](/blog/2026-05-30-japanese-spaghetti). Specifically, it was the dish on the Kimpton Shinjuku menu that I walked past every morning and never ordered. Five ingredients: butter, tamari, parmesan, green onion, pasta water. Done in ten minutes. The tamari and butter combination is one of those things that's almost too obvious once you make it — the kind of recipe that feels like you already knew it.
